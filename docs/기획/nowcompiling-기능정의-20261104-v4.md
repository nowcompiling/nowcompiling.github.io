### 1.1 모든 화면 공통 표시 기준

요구사항 1.2 화면 다듬기를 S01~S06 전부에 적용한다. 기능이 아니라 표시 기준이므로 기능ID 를 주지 않고, 와이어프레임·디자인 시스템이 이 절을 따른다.

- 바탕은 어둡게 둔다
- 폰 화면(가로 360px [가정])을 먼저 맞추고 PC 는 그다음에 맞춘다. 폰에서 옆으로 밀리는 화면이 없다
- 로고 없이 머리줄(S06)에 `nowcompiling` 글자를 둔다
- 인상: 전문적인 · 흥미로운 · 팀플레이(혼자지만 AI 비서들과 팀처럼 일한다). 피할 것: 기계적인 콘텐츠 느낌

## 2. 기능 목록

### 2.1 S00 운영자 작업

| 기능ID | 기능명 | 설명 | 근거 |
|---|---|---|---|
| S00-F01 | 초안 감추기 | 운영자가 글을 초안으로 두면 시스템이 그 글을 S01·S02·S03 어디에도 내보내지 않는다 | 3.5, 5(초안 노출 0건) |
| S00-F02 | 발행 | 운영자가 발행 표시를 하면 시스템이 10분 안에 그 글을 S01·S02·S03 에 올린다 | 3.5, 5(반영 10분 [가정]) |
| S00-F03 | 내림 | 운영자가 발행 글을 내림으로 바꾸면 시스템이 S01·S02 에서 빼고 그 글 주소를 S05 로 보낸다 | 3.6 |
| S00-F04 | 발행 조건 검사 | 운영자가 발행하려는 글에 글 종류가 정확히 1개가 아니거나, 사례 글에 캡처가 없으면 시스템이 발행하지 않고 운영자에게 사유를 알린다 | 5(글 종류 1개, 사례 글 캡처 1장 이상) |
| S00-F05 | 두 주소·보안 연결 | 방문자가 `nowcompiling.dev`·`www.nowcompiling.dev` 어느 쪽으로 오든 시스템이 같은 사이트를 https 로 보여 주고, http 로 오면 https 로 넘긴다 | 5(두 주소, 보안 연결) |
| S00-F06 | 대표 표시 | 운영자가 발행한 사례 글 1편에 대표 표시를 하면 시스템이 10분 안에 S01 의 대표 사례 글(S01-F07)을 그 글로 바꾼다 | 3.7 |
| S00-F07 | 대표 조건 검사 | 대표 표시가 없거나 둘 이상이거나 사례 글이 아닌 글에 붙어 있으면 시스템이 사이트를 바꾸지 않고 "대표 사례 글은 발행한 사례 글 중 정확히 1편이어야 합니다." 를 알린다. 대표 글을 내림으로 바꾸면 시스템이 사이트를 바꾸지 않고 "대표 사례 글은 내릴 수 없습니다. 다른 사례 글을 먼저 대표로 고르세요." 를 알린다 | 3.6a, 3.7a, 5(대표 사례 글 정확히 1편) |

### 2.2 S01 첫 화면

| 기능ID | 기능명 | 설명 | 근거 |
|---|---|---|---|
| S01-F01 | 정체성 표시 | 방문자가 첫 화면을 열면 시스템이 `HENRY`, 역할 두 줄 `Camping Developer` / `AI Automation Maker`, 핵심 문장 "돌아갈 때까지 만듭니다" 를 보여 준다. 핵심 문장은 대표 사례 글과 함께 첫 화면에서 가장 크게 보인다 | 3.1, 1.2 |
| S01-F02 | 나의 스토리 요약 | 시스템이 나의 스토리 요약 4줄과 "전체 읽기" 를 보여 주고, 방문자가 "전체 읽기" 를 누르면 S04 로 보낸다 | 3.1 |
| S01-F03 | 최신 글 | 시스템이 발행 글 중 최신 3편 [가정] 을 제목·글 종류와 함께 보여 주고, 방문자가 누르면 S03 으로 보낸다. 3편보다 적으면 있는 만큼 보여 준다. [추가] 대표 사례 글(S01-F07)은 최신 글에서 뺀다. 빼고 나서 0편이면 최신 글 칸을 감춘다 (11-04 사용자) | 3.1, 5(최신 글 3편) |
| S01-F04 | 하위 브랜드 칸 | 시스템이 운영 중인 하위 브랜드만 이름·한 줄 소개와 함께 보여 주고, 방문자가 누르면 그 서비스 주소를 연다. 지금은 가계부족 1개 | 3.1, 5(운영 중인 것만) |
| S01-F05 | 연락 주소 | 시스템이 `nowcompiling.dev@gmail.com` 을 보여 주고, 방문자가 누르면 메일 앱을 열어 받는 사람을 채운다 | 3.1, 3.4 |
| S01-F06 | 글 목록 가기 | 방문자가 "글 전체 보기" 를 누르면 시스템이 S02 로 보낸다 | 3.2 |
| S01-F07 | 대표 사례 글 | 방문자가 첫 화면을 열면 시스템이 운영자가 고른 사례 글 1편의 제목·한 줄 요약·"읽기" 를 핵심 문장과 함께 가장 크게 보여 주고, 방문자가 누르면 S03 으로 보낸다. 폰에서는 밀지 않고 처음 보이는 영역 안에 든다 | 3.1, 1.2, 6(폰 첫 화면 완료 조건) |

### 2.3 S02 글 목록

| S02-F01 | 최신순 목록 | 방문자가 글 목록을 열면 시스템이 발행 글 전체를 최신순으로 보여 주고, 방문자가 글을 누르면 S03 으로 보낸다. 글은 쓴 해마다 묶어 연도 아래에 쌓고, 한 줄에 날짜·제목·한 줄 요약·글 종류를 보여 준다 | 3.2 |

- 첫 화면 명함 홀로그램 GIF: 확정된 자산을 S01-F01 옆에 둔다.

- S01-F03 최신 글을 S02-F01 과 같은 줄 모양(날짜·제목·한 줄 요약·글 종류)으로: 두 곳 모양이 다르면 같은 글이 다른 것처럼 보인다.

# nowcompiling.dev 요구사항

## 1. 목적·범위

### 1.1 목적

비개발자 사장님이 사례 글을 읽고 "이 사람에게 내 업무 자동화를 맡겨도 되겠다"고 판단한 뒤, 그 자리에서 바로 연락하게 한다.

### 1.2 만들 것

- 첫 화면: 누구인지, 무엇을 하는지, 어떻게 연락하는지 한 화면에 보인다
- 글 목록: 발행한 글을 최신순으로 보고 종류별로 거른다
- 글 한 편 보기: 글 본문과 끝의 연락 안내
- 하위 브랜드 소개 칸: 첫 화면 안에서 서비스별 한 줄 소개. 주소가 열려 운영 중인 서비스만 넣는다. 지금은 가계부족 1개
- 첫 발행 글 2편 (둘 다 사례 글, 운영자 본인 업무를 자동화한 실제 사례)
  - 메일 자동 분류와 카카오톡 아침 요약
  - 가계부족
- 나의 스토리: HENRY 가 어떤 사람이고 왜 이 일을 하는지 들려주는 이야기. 첫 화면에 보인다
- 운영자의 글 발행: 운영자가 글을 써서 발행 표시를 하면 사이트에 올라간다
- [추가] 공통 머리줄: 모든 화면 위에 이름(누르면 첫 화면)과 "글"(누르면 글 목록)을 둔다 (11-04 기능정의 단계에서 승인, 상위 문서 반영)

### 1.3 안 만들 것

- 회원가입·로그인
- 댓글
- 문의 접수를 사이트에 저장하는 기능 (연락은 메일 주소로 받는다)
- 결제
- 사이트 안 검색
- 다국어
- 하위 브랜드별 개별 사이트 (이번 범위는 nowcompiling.dev 하나)
- 네이버 블로그 자동 재발행
- 메일 주소를 `@nowcompiling.dev` 로 받는 기능 (11-04 확정: 하지 않음)
- 카카오톡 채널 연락 (문의가 생기기 시작하면 다시 검토)
- 기존 `www.nowcompiling.dev` "AI 실험실" 글 옮겨 오기 (11-04 확정: 옮길 글 없음, 사이트를 통째로 교체)

## 3. 사용자 흐름

### 3.1 첫 화면

방문자가 `nowcompiling.dev` 또는 `www.nowcompiling.dev` 를 열면(명함 QR 포함) 시스템이 첫 화면을 보여 준다. 첫 화면에는 다음이 보인다.

- `HENRY`, 역할 두 줄 `Camping Developer` / `AI Automation Maker`, 핵심 문장
- 나의 스토리 — 첫 화면에는 요약 4줄과 "전체 읽기" 만 보이고, 누르면 전문을 보여 준다. 문안은 `nowcompiling-나의스토리-20261104-v1.md` (11-04 확정)
- 최신 글
- 하위 브랜드 소개 칸
- 연락 주소

### 3.2 글 목록

방문자가 글 목록을 열면 시스템이 발행한 글을 최신순으로 보여 준다. 방문자가 글 종류를 고르면 시스템이 그 종류의 글만 보여 준다.

- 예외 3.2a: 고른 종류에 글이 없으면 "아직 이 종류의 글이 없습니다." 를 보여 준다.

### 3.3 글 한 편 보기

방문자가 글을 누르면 시스템이 본문을 보여 주고, 글 끝에 연락 안내(연락 주소)를 붙인다. 사례 글은 다음 순서로 보인다.

1. 누구의 어떤 업무였나
2. 전: 걸린 시간·횟수
3. 무엇을 만들었나 (캡처 1장 이상)
4. 후: 줄어든 숫자
5. 비용과 기간
6. 연락 안내

- 예외 3.3a: 없는 글 주소나 내린 글 주소로 들어오면 "찾는 글이 없습니다." 와 글 목록으로 가는 링크를 보여 준다.

### 3.4 연락

방문자가 연락 주소를 누르면 시스템이 방문자의 메일 앱을 열고 받는 사람을 `nowcompiling.dev@gmail.com` 으로 채운다.

### 3.5 발행

운영자가 글을 쓰고 발행 표시를 하면 시스템이 사이트에 그 글을 올린다. 초안 표시가 된 글은 첫 화면·글 목록·글 주소 어디에서도 보이지 않는다.

### 3.6 내림

운영자가 발행한 글을 내림으로 바꾸면 시스템이 그 글을 첫 화면과 글 목록에서 빼고, 그 글 주소는 3.3a 처럼 처리한다.

## 4. 상태 정의

| 대상 | 상태 값 | 의미 | 전이 조건 |
|---|---|---|---|
| 글 | 초안 | 사이트에 보이지 않음 | 처음 쓴 글의 기본값 |
| 글 | 발행 | 사이트에 보임 | 운영자가 발행 표시 |
| 글 | 내림 | 다시 보이지 않음 | 운영자가 내림으로 바꿈. 다시 발행 표시하면 발행으로 |

## 5. 중요 규칙

| 규칙 | 값 | 위반 시 동작·메시지 |
|---|---|---|
| 글 하나의 글 종류 | 정확히 1개 | 종류가 없거나 둘 이상이면 발행되지 않는다 |
| 초안 노출 | 0건 | 초안이 어디서든 보이면 결함이다 |
| 첫 화면 최신 글 수 | 3편 [가정] | 3편보다 적으면 있는 만큼만 보인다 |
| 사례 글 캡처 | 1장 이상 | 없으면 발행하지 않는다 |
| 하위 브랜드 칸 | 주소가 열려 운영 중인 서비스만 | "준비 중" 표시로 미리 넣지 않는다 |
| 두 주소 | `nowcompiling.dev` 와 `www.nowcompiling.dev` 가 같은 사이트 | 한쪽만 열리면 결함이다 |
| 보안 연결 | 모든 주소가 https 로 열린다 | http 로 들어오면 https 로 넘긴다 |
| 발행 반영 시간 | 발행 표시 후 10분 이내 [가정] | 넘으면 운영자가 발행 실패를 확인한다 |

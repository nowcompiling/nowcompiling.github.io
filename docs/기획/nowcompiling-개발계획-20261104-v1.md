# nowcompiling.dev 개발 계획서

## 1. 대상 레포

| 항목 | 값 |
|---|---|
| 원격 | `github.com/nowcompiling/nowcompiling.github.io` (새로 만듦, 공개) |

| 기본 브랜치 | `main`. push 하면 자동 배포 |

## 2. 기술 구성

| 항목 | 선택 | 이유 |
|---|---|---|
| 생성기 | Astro 7.4.5 (npm 최신 안정판, 2026-11-04 조회) | 마크다운 글 모음·RSS·sitemap 을 기본 지원. 글이 늘어도 미리 만든 페이지라 속도가 일정하다 |
| 호스팅 | GitHub Pages | 11-04 확정 |
| 배포 | GitHub Actions — 공식 Astro 배포 액션 + Pages 배포 액션 | push 한 번이 곧 발행(S00-F02) |
| 런타임 | Node 26.5 (이 맥 설치본) | 빌드에만 쓴다. 방문자 쪽 서버 없음 |
| 이미지 | R2 `it-lab` 버킷 공개 링크 | 레포 용량을 늘리지 않는다 (아이데이션 v5 확정) |

### 2.1 DB 설계 — 해당 없음

글은 레포 안 마크다운 파일이다. 테이블·쿼리가 없다.

### 2.2 API 설계 — 해당 없음

방문자 요청은 미리 만든 페이지 파일로만 응답한다. API 가 없으므로 "API 없는 기능" 누락 점검도 해당 없다.

### 2.3 닫힌 값 (글 머리말에 이름으로 저장)

**글 종류 `kind`**

| 코드 | 의미 |
|---|---|
| `case` | 사례 |
| `tried` | 해봤더니 |
| `howto` | 따라하기 |

**글 상태 `status`** (전이는 요구사항 4. 상태 정의를 따른다)

| 코드 | 의미 |
|---|---|
| `draft` | 초안 — 빌드에서 뺀다 |
| `published` | 발행 |
| `unpublished` | 내림 — 빌드에서 뺀다. 주소는 404(S05) |

### 2.4 프론트

- 폰트 로딩: 없음. 명함과 같은 시스템 글꼴 `system-ui, -apple-system, "Apple SD Gothic Neo", sans-serif`. 내려받을 글꼴이 없어 첫 화면이 바로 뜬다.
- 색: 명함 v3 CSS 에서 가져온다. 바탕 `#07080d`·`#0d1226`, 면 `#12152a`, 본문 글자 `#dfe6f5`, 역할·강조 `#ffb36b`, 링크 `#bcd0ff`. 홀로그램용 무지개색(`#ff0080` 등)은 쓰지 않는다.
- 자바스크립트: 쓰지 않는다. 글 종류 거르기(S02-F02)도 종류별 페이지를 미리 만들어 링크로 처리한다.

## 4. 도메인 연결 (S00-F05)

사람이 Cloudflare 대시보드에서 바꾼다. 바꾸기 전 현재 레코드 값을 캡처해 둔다(되돌리기용).

| 순서 | 할 일 | 누가 |
|---|---|---|
| 4.1 | GitHub Pages 기본 주소 `nowcompiling.github.io` 에서 사이트가 열리는지 먼저 확인 | 나 |
| 4.2 | 기존 `www` 레코드(옛 AI 실험실 서버)를 지우고 `www` CNAME → `nowcompiling.github.io`, 프록시 끔 | 사용자 |
| 4.3 | 루트 `nowcompiling.dev` A 레코드를 GitHub Pages IP 4개로, 프록시 끔. IP 값은 착수 때 GitHub 문서에서 확인해 적어 준다 | 값은 내가, 적용은 사용자 |
| 4.4 | 레포 설정에서 사용자 도메인 지정 → 인증서 발급 후 "HTTPS 강제" 켬 | 나 |
| 4.5 | 두 주소·http 접속을 각각 확인 (완료 조건 3.1) | 나 |

- 되돌리기: 4.2·4.3 에서 캡처한 옛 값으로 레코드를 복원한다.
- 루트 레코드 변경은 `gagyebujok.nowcompiling.dev` 같은 하위 주소에 영향을 주지 않는다 — 하위 주소는 각자 별도 레코드다. 착수 때 레코드 목록으로 다시 확인한다.
- 루트 A 레코드는 지금 `114.206.88.93` 이고 응답이 없다(11-04 조회). 이 주소를 쓰는 다른 서비스가 없는지 사용자가 확인한다.
